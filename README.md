# The Spring Behind My Glimmer — Website

This folder is ready to publish as a static website.

## Files
- `index.html` — main page
- `styles.css` — design and responsive layout
- `script.js` — author's-note toggle and subtle reveal animation
- `assets/book-cover.png` — front cover
- `assets/book-back.png` — back/description artwork
- `assets/the-spring-behind-my-glimmer.pdf` — downloadable ebook

## Quickest way to publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you a public website link.

## Cloudflare Pages
You can also upload this folder to Cloudflare Pages using direct upload.

## Important
The ebook PDF is publicly accessible because the page offers a direct download.
Anyone who has the file URL may be able to share it.

## Customization
You can edit:
- text in `index.html`
- fonts, spacing, and appearance in `styles.css`
- the PDF or images inside `assets/`
